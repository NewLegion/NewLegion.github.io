Prospect engine

The foundation layer. Every lead enters GrowthLoop here.

Scraper — LinkedIn Sales Navigator import

Users paste a Sales Navigator search URL. GrowthLoop extracts the result set and normalizes profiles into structured records including name, title, company, email (inferred from domain), location, industry and connection count.

  • URL-based import: paste any Sales Navigator people/company search URL
  • Saved searches: store and re-run searches to monitor new entrants over time
  • Deduplication: automatic deduplication against existing database on import
  • Bulk CSV import: 4× faster import for lists over 10k rows (v2.4+)
  • Rich profiles: name, title, company, email, location, industry, mutual connections

Database & Lists

All imported prospects live in a searchable, filterable database. Users segment them into named lists for targeting with sequences or campaigns.

  • Full-text search across all profile fields
  • Filter by: company, title, location, industry, tags, list membership
  • Named lists with health indicators (active, bounced, unsubscribed)
  • Monitor view: track changes in target accounts over time

LinkedIn outreach

Automated, human-paced sequences that respect LinkedIn's daily action limits.

Sequence builder

A visual canvas where users compose multi-step LinkedIn flows. Steps connect top-to-bottom with configurable delays between actions.

1
View profile

Visits the prospect's LinkedIn profile to signal interest before reaching out.

2
Connection request

Sends a personalized connection note using dynamic variables: {{first}}, {{company}}, {{industry}}.

3
Wait (configurable delay)

Pauses the sequence for N days. Respects the prospect's local timezone and the user's configured sending window.

4
Message / InMail

Sends a follow-up message to connected prospects (or InMail for non-connections). Supports message templates with dynamic variables.

5
Conditional branches (v2.4+)

Split the flow based on whether a prospect replied, accepted the connection, or matches a custom tag.

Safety & limits

  • Daily action caps: connection requests ≤ 40/day, messages ≤ 80/day, profile visits ≤ 150/day
  • Sending window: actions only fire within user-defined hours in the prospect's local timezone
  • Weekend toggle: opt-in to Saturday/Sunday activity
  • Human pacing: randomized delays between individual actions

Sequence analytics

  • Step-level funnel: sent → accepted → replied per step
  • Aggregate reply rate, acceptance rate, meetings booked per sequence
  • Prospect-level status tracking throughout the flow

Email campaigns

Cold email at scale with deliverability at the core.

Campaign workflow

A guided 4-step wizard: define audience → compose message → review → launch.

  • Dynamic personalization: {{company}}, {{first}} and custom fields in subject and body
  • Provider support: Gmail, Outlook, or custom SMTP with full configuration
  • Daily sending cap: configurable limit to protect deliverability and stay within provider thresholds
  • Campaign states: Draft → Scheduled → Sending → Completed

Email warmup

Gradually ramps sending volume on new domains to build sender reputation before launching cold campaigns.

Tracking & compliance

  • Open tracking: invisible pixel inserted to measure open rates
  • Click tracking: link rewriting to measure CTR per campaign
  • Unsubscribe footer: 1-click opt-out automatically appended (recommended, toggleable)
  • Bounce & unsub tracking: automatically removes bounced and opted-out addresses from future sends

Analytics & dashboard

Cross-channel visibility without switching tools.

  • Outbound volume chart: messages sent + replies over the last 14 days, area chart
  • KPI cards: prospects scraped, messages sent, reply rate, meetings booked — each with delta vs. prior period and sparkline
  • Live activity feed: real-time stream of replies, accepts, opens, clicks, meetings and unsubscribes
  • Active campaigns table: cross-LinkedIn and email view with reply rates and status
  • Step-level funnels (v2.3+): visualize drop-off at each sequence step
